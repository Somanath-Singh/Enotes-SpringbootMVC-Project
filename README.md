# 📝 E-Notes Management System

A **full-stack Notes Management Web Application** built using **Spring Boot MVC** that enables users to securely create, organize, update, and manage their personal notes online.

The application demonstrates practical implementation of **Spring Boot, Spring MVC, Spring Security, Spring Data JPA (Hibernate), Thymeleaf, Bootstrap, MySQL, and CRUD operations** while following a clean layered MVC architecture.

---

# 📖 Project Overview

**E-Notes Management System** is a secure web application where users can register, log in, and manage their personal notes from anywhere.

Users can create new notes, edit existing notes, delete notes, and organize their information through an intuitive dashboard. The application also provides secure authentication to ensure that each user can access only their own notes.

This project demonstrates the development of a real-world Spring Boot MVC application with authentication, database integration, and complete CRUD functionality.

# 🏗️ Project Architecture

The application follows the **Layered MVC Architecture**.

```text
Client / Browser
       │
       ▼
   Controller
       │
       ▼
    Service
       │
       ▼
 Repository
       │
       ▼
 MySQL Database
```
